# Track Guide

This page provides an overview of the four learning tracks available in this book. Each track offers a different learning experience and final outcome.

## Track Overview

| Track | Name | Milestone | Complexity | Est. Time |
|-------|------|-----------|------------|-----------|
| <span class="track1-tag">T1</span> | Pixel Display | Display a single pixel | ⭐ | 5-10 hours |
| <span class="track2-tag">T2</span> | Pattern & Sprite Rendering | Animated sprites | ⭐⭐ | 15-20 hours |
| <span class="track3-tag">T3</span> | Interactive Graphics | Interactive demo | ⭐⭐⭐ | 25-35 hours |

## Track Guides

Each track has its own dedicated guide that provides a curated journey through the book's content. Choose the track that best matches your interests and available time:

### [Track 1 Guide: Pixel Display](tracks/track1-guide.md)

<div class="track1">

**Focus**: Getting the essential components working to display a single pixel on screen.

**You'll build**:
- Basic 6502 CPU with essential instructions
- Simplified memory mapping system
- Minimal PPU register implementation
- NROM (Mapper 0) support
- Test ROM that displays a single colored pixel

**Perfect for**:
- Complete beginners to emulation
- Those who want a quick win
- Learning the fundamentals of the NES architecture

</div>

### [Track 2 Guide: Pattern & Sprite Rendering](tracks/track2-guide.md)

<div class="track2">

**Focus**: Expanding the basic implementation to display patterns and sprites.

**You'll build**:
- More complete 6502 CPU implementation
- Tile and pattern rendering
- Sprite display capabilities
- Basic animation support
- More comprehensive PPU implementation

**Perfect for**:
- Those who want to see actual NES-style graphics
- Understanding how the NES displays images
- Creating simple visual demos

</div>

### [Track 3 Guide: Interactive Graphics](tracks/track3-guide.md)

<div class="track3">

**Focus**: Adding user input and creating interactive graphics.

**You'll build**:
- Complete CPU instruction set
- Full background rendering with scrolling
- Controller input support
- Basic game-like functionality
- Additional mapper support

**Perfect for**:
- Creating interactive demos
- Understanding how NES games handle input
- Building a foundation for game emulation

</div>

### [Track 4 Guide: Complete NES](tracks/track4-guide.md)

<div class="track4">

**Focus**: Implementing everything needed for a fully-functional NES emulator.

**You'll build**:
- Audio Processing Unit (APU)
- All memory mappers
- Cycle-accurate timing
- Full game compatibility
- Debugging tools
- Performance optimizations

**Perfect for**:
- Serious emulation enthusiasts
- Those who want to play actual NES games
- Understanding all aspects of the NES architecture

</div>

## Combining Tracks

You can also combine tracks in various ways:

- **Sequential Approach**: Complete Track 1, then move to Track 2, and so on
- **Focus on Graphics**: Complete Tracks 1-3 and skip audio implementation
- **Graphics & Audio**: Complete Tracks 1-2, skip input, and jump to audio in Track 4

The modular nature of the tracks allows you to customize your learning journey based on your interests and available time.

## Ready to Choose?

Select one of the track guides above to get a detailed roadmap for your chosen learning path, or start at the beginning with [NES Architecture Overview](part1-foundations/chapter1-1-nes-overview.md) and decide as you go!
